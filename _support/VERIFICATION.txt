Discord Voice Self-Bot V1.2.3 - File Log

Changed:
- Added rotating UTF-8 activity log at _support/logs/bot.log
- CMD/ACTION/OK/ERROR/WHY events write to the log file
- Voice join/move/leave steps and failure reasons are logged
- Go Live detect/watch/stop and kstream control steps are logged
- Sensitive fields such as token/secret/cookie/password/api_key are redacted
- LOG_TO_TERMINAL=false by default so Terminal stays minimal
- Log rotates at LOG_MAX_BYTES and keeps LOG_BACKUP_COUNT backups

Default log configuration:
LOG_FILE=_support/logs/bot.log
LOG_TO_TERMINAL=false
LOG_MAX_BYTES=2097152
LOG_BACKUP_COUNT=3
